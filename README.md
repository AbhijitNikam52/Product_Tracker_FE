# Product Tracker — Frontend

Frontend client for the Product Price Tracker built with React, Vite, Tailwind CSS, and Recharts.

## Setup & Running

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Configure environment variables**:
   Create a `.env` file from the example:
   ```bash
   cp .env.example .env
   ```
   Modify `VITE_API_URL` if your backend runs on a different port or host.

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Runs by default on [http://localhost:5173](http://localhost:5173).

4. **Production Build**:
   ```bash
   npm run build
   ```
